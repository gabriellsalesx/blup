# Contributing to Blup

*Versão em português abaixo.*

Thanks for wanting to help. Bug reports, ideas and pull requests are welcome.

## Before you start

- **Bugs and ideas:** open an issue first, with what happened and how to see
  it again. For a bigger change, talk about it in an issue before writing the
  code.
- **The license:** Blup is licensed under the [GNU AGPL-3.0](LICENSE).

## The Contributor License Agreement (CLA)

On your first pull request, a bot asks you to sign the
[Contributor License Agreement](CLA.md): one click, with your GitHub account,
once. You stay the author of your code; the agreement lets the project stay
under the AGPL-3.0 and also have commercial editions. Pull requests can only
be merged after it is signed.

## Pull requests

- One change per pull request, with a clear description of what and why.
- Run the tests: `go test ./...` (and `cd studio && go build -tags gtk3 .` for
  Blup Studio).
- Keep the style of the code around it.
- Text people see goes in both English and Portuguese.

# Contribuindo com o Blup

Obrigado por querer ajudar. Relatos de erro, ideias e pull requests são bem-vindos.

## Antes de começar

- **Erros e ideias:** abra uma issue primeiro, contando o que aconteceu e como
  ver de novo. Para uma mudança maior, converse numa issue antes de escrever o
  código.
- **A licença:** o Blup é licenciado sob a [GNU AGPL-3.0](LICENSE).

## O Acordo de Licença de Contribuidor (CLA)

No seu primeiro pull request, um robô pede que você assine o
[Acordo de Licença de Contribuidor](CLA.md): um clique, com a sua conta do
GitHub, uma vez só. Você continua autor do seu código; o acordo permite que o
projeto continue sob a AGPL-3.0 e também tenha edições comerciais. Os pull
requests só são aceitos depois da assinatura.

## Pull requests

- Uma mudança por pull request, com uma descrição clara do que e do porquê.
- Rode os testes: `go test ./...` (e `cd studio && go build -tags gtk3 .` para
  o Blup Studio).
- Siga o estilo do código ao redor.
- Textos que as pessoas veem vão em inglês e em português.
