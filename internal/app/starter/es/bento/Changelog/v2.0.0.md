Llegó **Blup Studio**, la app de Blup para Linux, macOS y Windows. Desde ahora es la forma recomendada de usar Blup. Obsidian y la línea de comandos siguen funcionando con las mismas notas.

- Editor con el texto ya formateado y la **vista previa** del sitio al lado.
- Pantallas para configurar el sitio: Sitio, Secciones, Autores, Comentarios, Cookies y Publicar.
- Terminal con agentes de IA, con copia de las notas antes y un botón para deshacer.
- Papelera para recuperar lo que se eliminó.
- Tema nuevo: **Nori**, un blog de una columna.
