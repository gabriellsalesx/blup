Una **bóveda de notas** es una carpeta de notas que **no se convierte en sitio**: solo notas, sin tema, sin vista previa y sin publicación. Sirve para el diario, las ideas, los estudios, los clientes, las tareas.

> [!info] Solo en Blup Studio
> Las bóvedas y sus herramientas (nota del día, mapa de notas, lienzos, dibujos y bases de datos) son del Studio. Las notas siguen siendo archivos Markdown comunes, que se abren en cualquier editor.

## Crear una bóveda

1. En la pantalla de inicio, haz clic en **Crear una bóveda de notas**.
2. Ponle un nombre, por ejemplo "Mis notas".
3. Revisa dónde se guardan las notas. Puedes **usar una carpeta que ya existe** o **elegir otra carpeta**.
4. Haz clic en **Crear bóveda**. Solo queda empezar a escribir.

## La pantalla de la bóveda

La barra lateral de la bóveda tiene:

| Ícono | Qué hace | Atajo |
| --- | --- | --- |
| Escribir | El editor y el árbol de notas | |
| Mapa de notas | Las notas como puntos unidos por los enlaces | `Ctrl+Alt+G` |
| Adjuntos | Imágenes y archivos | |
| Nuevo lienzo | Un tablero infinito con tarjetas y flechas | `Ctrl+Alt+C` |
| Nuevo dibujo | Formas, flechas y trazo libre | `Ctrl+Alt+W` |
| Nueva base de datos | Una lista de cosas con campos | `Ctrl+Alt+B` |
| Nota del día | La nota de hoy, con la hora | `Ctrl+Alt+D` |
| Sincronizar | Guarda las notas en la nube | |
| Papelera | Lo que se eliminó | |

El árbol muestra notas, carpetas, lienzos, dibujos y bases de datos, cada uno con su ícono.

## La página de la nota

- Arriba, el **nombre de la nota** en letra grande. Edítalo ahí y presiona Enter para renombrar el archivo.
- Debajo, las propiedades de la bóveda: **creada**, **actualizada** y **etiquetas**. La fecha de actualización cambia sola cuando editas el texto.
- Al pie de la nota, el panel **Mencionada en**: las notas que tienen un enlace a esta, con las líneas donde aparece. Un clic las abre.

## Etiquetas

Escribe la etiqueta y presiona Enter o coma. El Studio sugiere las etiquetas que ya usas, de las más usadas a las menos.

> [!tip] Etiquetas heredadas de la carpeta
> Una nota nueva en una carpeta recibe las etiquetas que ya tiene la mayoría de las notas de esa carpeta. Así, la carpeta "Reuniones" mantiene la etiqueta "reunion" sin que tengas que acordarte.

## Organizar arrastrando

Arrastra una nota o carpeta sobre una carpeta para moverla. Suéltala en el espacio vacío debajo del árbol para mandarla a la raíz. Los enlaces de las otras notas se corrigen solos.

## Guardar en la nube

Las bóvedas se sincronizan igual que los sitios: con Blup Cloud (cifrado de extremo a extremo) o con un repositorio privado de GitHub. Consulta [Sincronizar las notas](../Blup%20Cloud/Sincronizar%20las%20notas.md).
