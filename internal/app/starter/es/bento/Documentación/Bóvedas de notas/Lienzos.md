Un **lienzo** es un tablero sin bordes para organizar ideas: tarjetas de texto, notas de la bóveda, enlaces web y grupos, unidos con flechas.

## Crear

Haz clic en **Nuevo lienzo** en la barra lateral (`Ctrl+Alt+C`), usa el menú de una carpeta o escribe `/` en una nota y elige **Nuevo lienzo**. El Studio crea el archivo al momento, sin pedir nombre (en la carpeta **Lienzos**, o en la carpeta cuyo menú usaste), y lo abre. Cámbiale el nombre después desde el árbol.

## Usar

- **Doble clic** en un espacio vacío crea una tarjeta de texto. El texto acepta Markdown.
- **Arrastra una nota del árbol** al lienzo: se convierte en una tarjeta que muestra el texto de la nota (o la imagen).
- **Arrastra desde el punto lateral** de una tarjeta hasta otra para crear una flecha. La flecha puede tener texto y color.
- **Arrastra el espacio vacío** o usa la rueda para moverte. **Ctrl y la rueda** (o pellizcar) acercan.

## Teclado

| Acción | Teclas |
| --- | --- |
| Editar lo seleccionado | Enter |
| Eliminar | Delete o Backspace |
| Seleccionar todo | `Ctrl+A` |
| Deshacer y rehacer | `Ctrl+Z`, `Ctrl+Shift+Z` o `Ctrl+Y` |
| Pantalla completa | F, o `F11` |

En pantalla completa, el lienzo ocupa toda la ventana. Esc sale.

> [!info] Formato abierto
> El lienzo se guarda en el formato abierto JSON Canvas, en archivos `.canvas`. Se guarda solo.
