Un **dibujo** es una hoja para bocetar: flujos, esquemas, mapas mentales.

## Crear

Haz clic en **Nuevo dibujo** en la barra lateral (`Ctrl+Alt+W`), usa el menú de una carpeta o escribe `/` en una nota y elige **Nuevo dibujo**. El Studio crea el archivo en la carpeta **Dibujos** (o en la carpeta del menú) y lo abre.

## Herramientas

Cada herramienta tiene una letra:

| Letra | Herramienta |
| --- | --- |
| H | Mover el lienzo |
| V | Seleccionar |
| R | Rectángulo |
| D | Rombo |
| O | Elipse |
| A | Flecha |
| L | Línea |
| P | Dibujo libre |
| T | Texto |
| E | Borrador |

También puedes pegar imágenes. Cada elemento tiene color, relleno (suave o sólido), grosor, trazo discontinuo y tamaño de texto.

## Atajos

- **Espacio** mantenido mueve el lienzo.
- Las **flechas** mueven lo seleccionado (con Shift, de 10 en 10).
- **Enter** escribe dentro de la forma o del texto.
- `Ctrl+D` duplica.
- `Ctrl+=`, `Ctrl+-` y `Ctrl+0` acercan, alejan y encuadran.
- **F** o `F11` activa la pantalla completa. Esc sale.

## Exportar

**Exportar PNG** guarda una imagen del dibujo en Adjuntos, lista para usar en una nota.

> [!info] Se guarda solo
> El dibujo se guarda en archivos `.draw` mientras trabajas.
