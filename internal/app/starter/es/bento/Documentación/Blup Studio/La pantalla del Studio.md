Al abrir un sitio, el Studio muestra el área de trabajo. De izquierda a derecha:

1. **Barra lateral**: los íconos de las pantallas.
2. **Árbol de notas**: las carpetas y notas del sitio.
3. **Editor**: la nota abierta.
4. **Vista previa**: el sitio de verdad, al lado.
5. **Terminal** (opcional): abajo, cuando la abres.

Arriba están los botones **Vista previa**, **Sincronizar** y **Publicar**.

![Blup en la terminal](../../Adjuntos/blup-terminal.jpg)

## La barra lateral

Pasa el mouse sobre un ícono para ver su nombre. ¿Prefieres ver siempre los nombres? En **Configuración > Apariencia**, activa **Mostrar nombres en el menú lateral**.

En un **sitio**, las pantallas vienen en grupos:

| Grupo | Pantallas |
| --- | --- |
| Contenido | Escribir, Adjuntos, Autores |
| Sitio | Sitio, Secciones (solo en Bento), Idiomas |
| Público | Comentarios, Feedback (en Bento, con la sección) y Podcast (en los blogs, con la sección) |
| Privacidad | Cookies y estadísticas |
| Abajo | Publicar, Papelera y la terminal |

En una **bóveda de notas**, la barra cambia: Escribir, Mapa de notas y Adjuntos; después Nuevo lienzo, Nuevo dibujo, Nueva base de datos y Nota del día; abajo, Sincronizar, Papelera y la terminal. Consulta [Qué es una bóveda](../Bóvedas%20de%20notas/Qué%20es%20una%20bóveda.md).

Al pie de la barra están la **Ayuda** (abre esta documentación), el **engranaje** de la [Configuración del Studio](Configuración%20del%20Studio.md) y el **selector de sitio**.

## El selector de sitio

Haz clic en él para cambiar de sitio o de bóveda sin volver a la pantalla de inicio. Separa **Sitios** y **Bóvedas**, muestra primero los que abriste hace poco (hasta cinco de cada uno) y tiene **Ver todos** y **Pantalla de inicio**.

## El árbol de notas

- **Archivos** muestra las carpetas y notas. **Buscar** busca en el nombre y en el texto de las notas, sin importar acentos ni mayúsculas, y muestra las líneas encontradas.
- **Nueva nota** y **Nueva carpeta** crean en el lugar: aparece un campo de nombre dentro de la carpeta elegida; Enter crea, Esc cancela.
- Haz clic en una carpeta para abrirla o cerrarla. Pasa a ser el lugar de las notas nuevas.
- **Expandir todo** y **Contraer todo** abren y cierran todas las carpetas.

El clic derecho en una nota abre el menú:

| Opción | Qué hace |
| --- | --- |
| Nueva nota aquí, Nueva carpeta aquí | Crea dentro de la carpeta |
| Renombrar | Cambia el nombre. Los enlaces de las otras notas se corrigen |
| Mover a… | Elige otra carpeta. Los enlaces también se corrigen |
| Hacer una copia | Crea "Nombre 2" al lado |
| Copiar enlace de la nota | Para pegarlo en otra nota |
| Mostrar en la carpeta del sistema | Abre el administrador de archivos |
| Exportar como HTML | Una sola página, con las imágenes dentro |
| Imprimir o guardar como PDF | Abre la impresión del sistema |
| Versiones anteriores | Con Blup Cloud, muestra el historial de la nota |
| Eliminar | Va a la Papelera, y se puede restaurar |

Las carpetas de autores y de adjuntos no aparecen en el árbol: tienen pantallas propias, **Autores** y **Adjuntos**.

## Guardado

El Studio guarda solo mientras escribes, y antes de cambiar de nota o salir. El estado aparece en la pantalla: guardado, guardando o sin guardar. `Ctrl+S` también guarda.

Si una nota cambia fuera del Studio (en Obsidian o por una IA en la terminal), el árbol se actualiza. Si estabas editando esa misma nota, el Studio avisa y te deja elegir entre **Cargar la nueva** y **Conservar la mía**.

## Atajos principales

| Acción | Teclas |
| --- | --- |
| Nueva nota | `Ctrl+N` |
| Buscar notas | `Ctrl+Shift+F` |
| Mostrar u ocultar el panel de archivos | `Ctrl+Alt+S` |
| Activar o desactivar la vista previa | `Ctrl+Alt+P` |
| Abrir o cerrar la terminal | Ctrl y la tecla del acento grave |
| Configuración | `Ctrl+,` |

Todos se pueden cambiar o desactivar en **Configuración > Atajos**.

> [!tip] El Studio desde cualquier lugar
> El atajo global `Alt+Espacio` muestra y oculta Blup Studio aunque haya otro programa delante. Puedes cambiarlo en la configuración.
