La pantalla **Adjuntos** muestra las imágenes y archivos que usan las notas. Llegan solos cuando pegas o arrastras una imagen, o eliges una portada, el logo o la foto de un autor.

## Lo que puedes hacer

- **Filtrar**: Todos, Imágenes, Otros y **Sin usar**.
- **Buscar por nombre**.
- **Agregar archivos** desde la computadora.
- Ver **Usado en**: las notas que usan el archivo, con un enlace para abrir cada una.
- **Renombrar**: las notas que usan el archivo se actualizan.
- **Copiar para pegar en una nota**: copia el enlace listo.
- **Abrir en la computadora**, con el programa predeterminado.
- **Eliminar**: va a la Papelera. Si alguna nota usa el archivo, el Studio avisa antes.

> [!tip] Lo que no se usa no va al sitio
> Un archivo que ninguna nota usa no se publica. El filtro **Sin usar** ayuda a hacer limpieza.

## Lo que hace el sitio con las imágenes

Al publicar, Blup genera versiones más pequeñas y en WebP de cada imagen y le entrega al navegador solo el tamaño que necesita. Consulta [Enlaces e imágenes](../Escribiendo/Enlaces%20e%20imágenes.md).

## Fuera del Studio

Los adjuntos son archivos comunes, en la carpeta **Adjuntos** de las notas.
