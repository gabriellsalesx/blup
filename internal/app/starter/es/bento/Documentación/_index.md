**Blup** convierte tus notas en un sitio rápido y también guarda notas solo para ti, en las **bóvedas de notas**. La forma recomendada de usarlo es **Blup Studio**, la app para computadora (Linux, macOS y Windows): escribes, ves la vista previa del sitio al lado y publicas con un botón.

Las notas son archivos Markdown comunes, en una carpeta de tu computadora. Para generar y publicar desde la terminal, también existe la línea de comandos `blup`.

## Lo más destacado

- **IA integrada en el Studio**: una voz lee tus posts, la IA traduce las notas y agentes como Claude Code y Codex trabajan en las notas desde la terminal. Paga con el plan de Blup Cloud, con tu clave de OpenRouter, o usa la voz y la traducción en la computadora, gratis.
- **Sitios en varios idiomas**: cada nota recibe su traducción en una carpeta `en`, `es` o `pt` junto a ella, y el sitio muestra un selector de idioma arriba.
- **Podcast en los blogs**: en los temas Mochi y Nori, las narraciones se vuelven episodios con feed para Spotify y Apple Podcasts.

Esta documentación es, en sí misma, un ejemplo: cada página es una nota de la carpeta **Documentación**, y cada grupo del menú lateral es una subcarpeta.

## Qué hay en cada grupo

| Grupo | Para qué |
| --- | --- |
| Primeros pasos | Instalar, crear el primer sitio y entender las carpetas |
| Blup Studio | Cada parte de la app: editor, vista previa, propiedades, adjuntos, papelera, configuración y terminal |
| Bóvedas de notas | Notas solo para ti: nota del día, mapa, lienzos, dibujos y bases de datos |
| Escribiendo | Markdown, propiedades, enlaces, imágenes, callouts y fórmulas |
| Configuración del sitio | Nombre, logo, menú, redes, autores, sitios en varios idiomas, cookies y contraseñas |
| Funciones con IA | Narración de los posts, traducción, podcast de los blogs y cómo se paga la IA |
| Secciones del Bento | Documentación, roadmap, changelog, centro de ayuda, blog y feedback |
| Publicación | Poner el sitio en línea y usar un dominio tuyo |
| Blup Cloud | Cuenta, planes, sincronización cifrada y sitios en Blup |
| Línea de comandos | El `blup` en la terminal, para quien prefiere la terminal o quiere automatizar |
