| | Blup Cloud | Cloudflare Pages | GitHub Pages |
| --- | --- | --- | --- |
| Precio | En los planes de pago | Gratis | Gratis |
| Dirección | `tusitio.getblup.site` | `misitio.pages.dev` | `tunombre.github.io/misitio` |
| Cuenta | La de Blup Cloud | Una cuenta de Cloudflare | Una cuenta de GitHub |
| Configurar | Nada | Una llave de acceso | Una llave de acceso |

## ¿Cuál elijo?

- **Blup Cloud** es el camino más sencillo: eliges la dirección y publicas. El Studio comprueba si el nombre está libre mientras escribes.
- **Cloudflare Pages** y **GitHub Pages** son gratuitos y piden una cuenta en el servicio y una llave de acceso, que Blup te ayuda a crear.

En los tres, Blup genera el sitio en tu computadora y envía solo los archivos listos.
