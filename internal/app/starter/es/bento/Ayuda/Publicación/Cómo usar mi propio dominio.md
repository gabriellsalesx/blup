## En Cloudflare Pages y en GitHub Pages

1. Publica el sitio una vez.
2. En la pantalla **Publicar**, indica el dominio.
3. El Studio muestra los registros que tienes que crear donde compraste el dominio.
4. Espera la confirmación. Después, vuelve a publicar para que los enlaces usen el dominio nuevo.

## En Blup Cloud

El dominio propio en los sitios de Blup Cloud estará en los planes **Max** y **Ultra** y todavía está llegando. Mientras tanto, el sitio queda en la dirección `tusitio.getblup.site`.
