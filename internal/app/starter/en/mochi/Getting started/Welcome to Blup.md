**Blup** turns an Obsidian folder into a fast, good looking, lightweight website. You write in Obsidian as always; Blup takes care of the rest: it builds the pages, the search, the optimized images, the SEO and the publishing.

This whole blog is an example. Each post teaches one part, and each post's note shows how it was written. Open this note in Obsidian and compare it with the page.

## How notes become pages

| In Obsidian | On the site |
| --- | --- |
| The site folder | The whole site |
| The folder's **_index** note | The home page and the site settings |
| Each note | A post |
| Each subfolder | A section, with its own page and menu item |
| A subfolder's **_index** note | The section's title and description |
| Note properties | Date, tags, cover, authors, password... |

This post, for example, is in the **Getting started** folder. That is why it shows up in the section with the same name.

## What comes ready

- Light and dark theme, following the system.
- Search across the whole site, with no server.
- Covers and images resized for you.
- A page for each tag and each author.
- Table of contents, reading progress bar and share buttons.
- Obsidian callouts, math, tables and code.
- Password protected posts.
- RSS feed and a share card for social networks.
