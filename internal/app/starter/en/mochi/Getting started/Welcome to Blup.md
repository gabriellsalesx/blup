**Blup** turns notes into a fast, good looking and light website. You write; Blup takes care of the rest: it makes the pages, the search, the optimized images, the SEO and the publishing.

This whole blog is an example. Each post teaches one part, and each post's note shows how it was written. Open this note and compare it with the page.

## Sites and note vaults

Blup keeps two kinds of things:

- **Sites**: notes that become a published website, like this blog.
- **Note vaults**: notes just for you, that never become a site. See [Note vaults](Note%20vaults.md).

Either way, the notes are plain Markdown files in a folder on your computer. Nothing is locked into one app.

## Blup Studio or Obsidian?

The recommended way to use Blup is **Blup Studio**, an app for Linux, macOS and Windows. In it you write, see the preview and publish, all in the same window.

If you like **Obsidian**, you can keep using it: the notes are the same, and the same folder opens in both. On the Obsidian side, the `blup` command line makes the preview and publishes. The posts in this blog show both ways whenever there are two.

Some things only the Studio does:

- an editor with a live preview of the site, next to the text;
- screens to set up the site: Site, Sections, Authors, Languages, Comments, Cookies and statistics, Podcast and Publish;
- translating notes into other languages;
- narrating posts as audio;
- note vaults, with canvas, drawings, databases, note of the day and map of notes;
- syncing and publishing through Blup Cloud;
- a terminal with AI agents;
- trash and history.

## How notes become pages

| In the notes | On the site |
| --- | --- |
| The site folder | The whole site |
| The folder's **_index** note | The home page and the site settings |
| Each note | A post |
| Each folder inside it | A section, with its own page and a menu item |
| A folder's **_index** note | The section's title and description |
| The note's properties | Date, tags, cover, authors, password... |

This post, for example, is in the **Getting started** folder. That is why it shows up in the section with the same name.

## What comes ready

- Light and dark theme, or the system's.
- Search across the whole site, with no server.
- Covers and images resized on their own.
- A page for each tag and each author.
- Table of contents, reading bar and share buttons on posts.
- Callouts, formulas, tables and code.
- Password protected posts.
- RSS feed and a share card for social networks.
