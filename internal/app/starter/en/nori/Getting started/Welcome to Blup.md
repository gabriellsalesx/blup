**Blup** turns a folder of notes into a fast, good looking, lightweight website. You write in Blup Studio; Blup takes care of the rest: it builds the pages, the search, the optimized images, the SEO and the publishing.

This whole blog is an example. Each post teaches one part, and each post's note shows how it was written. Open this note in the Studio and compare it with the page in the preview.

## How notes become pages

| In the Studio | On the site |
| --- | --- |
| The site folder | The whole site |
| The folder's **_index** note | The home page and the site settings |
| Each note | A post |
| Each subfolder | A section, with its own page and menu item |
| A subfolder's **_index** note | The section's title and description |
| The note's properties | Date, tags, cover, authors, password... |

This post, for example, is in the **Getting started** folder. That is why it shows up in the section with the same name.

## What comes ready

- Light and dark theme, or the system's.
- Search across the whole site, with no server.
- Covers and images resized for you.
- A page for each tag and each author.
- Comments and reactions at the end of the posts.
- Callouts, math, tables and code.
- Password protected posts.
- RSS feed, with a button that copies its address.
