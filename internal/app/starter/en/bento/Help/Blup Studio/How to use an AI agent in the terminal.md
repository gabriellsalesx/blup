---
title: How do I use an AI agent in the Studio's terminal?
description: Open an agent in your notes folder, and undo what it changed if you want.
weight: 6
---
The Studio has a terminal below the editor, already open in your notes folder.

1. Open the terminal with the button in the left bar.
2. Pick an agent installed on your computer: Claude Code, Codex, OpenCode, Gemini CLI or Antigravity.
3. Ask for whatever you want, like reviewing a text or creating a page.

Before the agent starts, the Studio keeps a copy of your notes. Afterwards, you can review what it changed and **Undo all** in one go.

> [!info] The Studio doesn't install the agents
> Install the agent you prefer first. The Studio only finds the ones already on your computer.
