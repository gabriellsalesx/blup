---
title: How do I change the site's name, logo and menu?
description: All on the Site screen in Blup Studio.
weight: 1
---
1. In the left bar, open **Site**.
2. Fill in the name, the description and the default author.
3. Pick the **logo** and the **favicon** (the icon on the browser tab).
4. If the logo already has the name written in it, turn off **Show the name next to the logo**.
5. Build the **menu**: add items, change the order by dragging, and drop one item onto another to make a submenu.
6. Set up the **Top button** in the top right corner.
7. Under **Social links**, click the button for the network (Instagram, X, LinkedIn, YouTube, Discord, GitHub, Facebook, WhatsApp or e-mail) and complete the address.

The changes show in the preview without reloading.

> [!tip] In Obsidian
> The same settings live in the properties of the **_index** note in the site folder.
