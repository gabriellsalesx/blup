## On Cloudflare Pages and GitHub Pages

1. Publish the site once.
2. On the **Publish** screen, enter the domain.
3. The Studio shows the records you need to create where you bought the domain.
4. Wait for the confirmation. Then publish again so the links use the new domain.

## On Blup Cloud

Custom domains for Blup Cloud sites come with the **Max** and **Ultra** plans and are still on the way. Until then, the site lives at `yoursite.getblup.site`.
