---
title: How do I turn on comments, votes and reactions?
description: Visitors comment, vote and react by signing in with GitHub.
weight: 6
---
1. In the Studio, open **Comments** in the left bar and turn it on.
2. Blup creates a public repository on your GitHub to keep the conversations.
3. Install the **Blup Comments** app on that repository, as the screen explains.
4. Publish the site.

After that, visitors can vote on the roadmap, react to changelog versions and comment on posts. To take part, people sign in with GitHub, which keeps spam away.

On the command line, run `blup customize` and choose **Comments and reactions**.
