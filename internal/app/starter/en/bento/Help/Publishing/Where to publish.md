title: Where can I publish my site?
description: With Blup Cloud, with nothing to set up, or for free on Cloudflare Workers or GitHub Pages.
weight: 1

| | Blup Cloud | Cloudflare Workers | GitHub Pages |
| --- | --- | --- | --- |
| Price | On paid plans | Free | Free |
| Address | `yoursite.getblup.site` | `mysite.youraccount.workers.dev` | `yourname.github.io/mysite` |
| Account | Your Blup Cloud account | A Cloudflare account | A GitHub account |
| Setup | Nothing | An access key | An access key |

## Which one should I pick?

- **Blup Cloud** is the simplest way: you pick the address and publish. The Studio checks whether the name is free as you type.
- **Cloudflare Workers** and **GitHub Pages** are free and need an account with the service and an access key, which Blup helps you create.

In all three, Blup builds the site on your computer and sends only the finished files. A custom domain is only through Blup Cloud, on the Max and Ultra plans.
