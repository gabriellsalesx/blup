---
title: The access key doesn't work
description: Expired key or missing permission.
weight: 3
---
Blup checks the key before using it. If it doesn't work, it explains why and asks for another.

- **GitHub**: when creating the key, under **Repository access**, choose **All repositories**.
- **Cloudflare**: the key needs the **Cloudflare Pages: Edit** permission.
- Keys expire. Create another the same way and paste it when Blup asks.
