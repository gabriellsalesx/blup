---
title: The image doesn't show up
description: Check the file name and where it is.
weight: 2
---
- The image must be **inside the vault**.
- In the `image` property, use the file name: `"[[cover.jpg]]"`, with quotes.
- Accepted formats: PNG, JPG, WebP, AVIF, GIF, SVG, BMP and TIFF.
- If you renamed the file outside Obsidian, the link in the note still has the old name.
