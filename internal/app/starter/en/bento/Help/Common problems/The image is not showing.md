---
title: Why is the image not showing?
description: Check the file name and where the file is.
weight: 2
---
- The image needs to be **inside your notes**, ideally in the attachments folder.
- In the `image` property, use the file name in quotes: `"[[cover.jpg]]"`.
- Supported formats: PNG, JPG, WebP, AVIF, GIF, SVG, BMP and TIFF.
- Did you rename the file outside the Studio or Obsidian? The link in the note still has the old name. In the Studio, rename it on the **Attachments** screen, which fixes the links on its own.
