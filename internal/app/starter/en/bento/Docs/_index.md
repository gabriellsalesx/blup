**Blup** turns an Obsidian folder into a fast website. You write in Obsidian; Blup builds the pages, the search, the optimized images, the SEO, and publishes for free.

These docs are an example themselves: each page is a note in the **Docs** folder of your vault, and each group in the sidebar is a subfolder.

## Where to start

- Never used it? Start with [Installation](Getting%20started/Installation.md).
- Already have the site? See [Notes and properties](Writing/Notes%20and%20properties.md).
- Want to understand each section of this site? See [Bento sections](Bento%20sections/Docs.md).
- Ready to publish? See [Publish](CLI/Publish.md).

> [!tip] This is the first page
> The text you are reading lives in the **_index** note of the Docs folder. Every folder can have an _index note: it becomes the folder's opening page.
