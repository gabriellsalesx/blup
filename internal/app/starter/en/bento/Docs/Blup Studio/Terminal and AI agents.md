The Studio has a built-in terminal that opens at the bottom of the window. It already starts **in the notes folder** of the open site or vault.

## Open it

- Click the terminal icon at the end of the side strip, or use Ctrl and the backtick key.
- **New terminal** opens another tab. Each tab has a menu to rename, duplicate, restart and close it.
- **Minimize** hides the panel, and the terminals keep running.

## Open an AI

The **Open an AI** button lists the terminal AI agents installed on your computer:

- Claude Code
- Codex
- OpenCode
- Gemini CLI
- Antigravity

Pick one and it starts inside the terminal, already in your notes folder. When you leave the agent, the terminal stays open.

> [!info] The Studio doesn't install these programs
> It only recognizes the ones already installed. If none are, the Studio shows links to learn about each one. The list is in **Settings > Terminal > AIs in the terminal**.

## The guide for the AI

When you open the terminal, the Studio creates an `AGENTS.md` file in your notes, which explains to the AI how a Blup site works (folders, properties, links). `CLAUDE.md` and `GEMINI.md` point to it. These files never become pages, and the Studio doesn't rewrite them: feel free to edit them.

## See and undo what the AI changed

Before the AI starts, the Studio keeps a copy of your notes.

1. After the AI has worked, click **See what the AI changed**.
2. The Studio lists every **new**, **changed** or **deleted** note.
3. Like it? Carry on. Don't like it? **Undo all** puts the notes back as they were before the AI. What it created goes to the Trash.

> [!warning] Only with an agent
> The copy is made when you open an agent with the **Open an AI** button. A plain terminal, without an agent, keeps no copy. The Studio keeps the five most recent copies, and very large files may be left out.
