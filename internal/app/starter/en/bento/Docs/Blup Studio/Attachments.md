The **Attachments** screen shows the images and files your notes use. They arrive on their own when you paste or drag an image, or pick a cover, the logo or an author's photo.

## What you can do

- **Filter**: All, Images, Others and **Unused**.
- **Search by name**.
- **Add files** from your computer.
- See **Used in**: the notes that use the file, with a link to open each one.
- **Rename**: the notes that use the file are updated.
- **Copy to paste in a note**: copies a ready-made link.
- **Open on the computer**, with the default app.
- **Delete**: it goes to the Trash. If a note uses the file, the Studio warns you first.

> [!tip] Unused files stay off the site
> A file that no note uses is not published. The **Unused** filter helps you tidy up.

## What the site does with images

When publishing, Blup makes smaller WebP versions of each image and sends the browser only the size it needs. See [Links and images](../Writing/Links%20and%20images.md).

## Where they live

Attachments live in the **Attachments** folder of your notes.
