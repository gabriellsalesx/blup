Above the text of each note sits the **Properties** panel. It is a form for the note's block of properties (the front matter), so you never have to write YAML.

## The fields

| Field | What it does |
| --- | --- |
| Title | The page title. Left empty, the note's name is used |
| Description | Shows in lists, on Google and when shared |
| Date | The post's date |
| Tags | Type and press Enter |
| Authors | Pick from the list, or type the name and press Enter |
| Cover | The cover image |
| Draft | Only in the preview, never published |
| Hidden | Published, but left out of lists and Google |
| Password | Asks for a password to read: the **general password** or the post's **own password** |

In Bento you also see these, when they make sense:

- **Order** (`weight`): lower shows first.
- **Column** and **Category**: on roadmap items.
- **Collection icon**: on the _index note of a Help center collection. See [Help center](../Bento%20sections/Help%20center.md).

**More options** holds the fields you use less. Properties the form doesn't know stay in the note, untouched.

> [!tip] Author without a photo?
> If you type a name that has no note in the authors folder, the Studio tells you: it shows up with just the name, no photo. Create the profile on the **Authors** screen.

## Narration

In posts and regular pages, the panel has a **Narration** block: **Make narration** creates an audio version of the text, and the site shows a player at the top. See [Post narration](../AI%20features/Post%20narration.md).

## Languages

Every note of a site has a **Languages** block: the original and each language, with **Translate**, **Open**, **Translate again** and **Mark as reviewed**. See [Multilingual sites](../Site%20setup/Multilingual%20sites.md).

## By hand

You can write the same properties by hand at the top of the note. See the full list in [Notes and properties](../Writing/Notes%20and%20properties.md).
