title: Changelog
description: What's new in each version, from newest to oldest.

---
The changelog is a folder whose **_index** has `blup: changelog`. Each note is a version.

```yaml
---
title: Version 1.3.0
date: 2026-10-28
tags: [New, Improvement]
---
- Sync the notes with GitHub.
- Faster search.
```

- **date** orders the versions: the newest is on top.
- **tags** become colored labels (each name always gets the same color) and filter pages.
- The note's full text shows up in the list; the title leads to the version's page.
- With many versions, the list gets a load more button.

> [!tip] One note per version
> Name the note after the version, like `v1.3.0`, and use **title** for the nice text.
