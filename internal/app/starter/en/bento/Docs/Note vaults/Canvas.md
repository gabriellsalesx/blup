A **canvas** is a board with no edges for organizing ideas: text cards, notes from the vault, web links and groups, connected by arrows.

## Create one

Click **New canvas** in the side strip (`Ctrl+Alt+C`), use a folder's menu, or type `/` in a note and choose **New canvas**. The Studio creates the file right away, without asking for a name (in the **Canvas** folder, or in the folder whose menu you used), and opens it. Rename it later from the tree.

## Use it

- **Double-click** an empty spot to create a text card. The text accepts Markdown.
- **Drag a note from the tree** onto the canvas: it becomes a card that shows the note's text (or the image).
- **Drag from the side dot** of a card to another card to create an arrow. Arrows can have text and color.
- **Drag an empty spot** or use the scroll wheel to move around. **Ctrl and the wheel** (or a pinch) zoom in.

## Keyboard

| Action | Keys |
| --- | --- |
| Edit the selected item | Enter |
| Delete | Delete or Backspace |
| Select all | `Ctrl+A` |
| Undo and redo | `Ctrl+Z`, `Ctrl+Shift+Z` or `Ctrl+Y` |
| Full screen | F, or `F11` |

In full screen, the canvas fills the whole window. Esc leaves it.

> [!info] Open format
> The canvas is saved in the open JSON Canvas format, as `.canvas` files. It saves on its own.
