A **note vault** is a folder of notes that **never becomes a site**: just notes, with no theme, no preview and no publishing. It's for your journal, ideas, studies, clients and tasks.

> [!info] Only in Blup Studio
> Vaults and their tools (note of the day, map of notes, canvas, drawings and databases) belong to the Studio. The notes are still plain Markdown files that open in any editor.

## Create a vault

1. On the home screen, click **Create a note vault**.
2. Give it a name, like "My notes".
3. Check where the notes will live. You can **use a folder that already exists** or **pick another folder**.
4. Click **Create vault**. Then just start writing.

## The vault window

The vault's side strip has:

| Icon | What it does | Shortcut |
| --- | --- | --- |
| Write | The editor and the note tree | |
| Map of notes | Your notes as dots connected by links | `Ctrl+Alt+G` |
| Attachments | Images and files | |
| New canvas | An endless board with cards and arrows | `Ctrl+Alt+C` |
| New drawing | Shapes, arrows and freehand lines | `Ctrl+Alt+W` |
| New database | A list of things with fields | `Ctrl+Alt+B` |
| Note of the day | Today's note, with the time | `Ctrl+Alt+D` |
| Sync | Keeps your notes in the cloud | |
| Trash | What was deleted | |

The tree shows notes, folders, canvases, drawings and databases, each with its own icon.

## The note page

- At the top, the **note's name** in large letters. Edit it there and press Enter to rename the file.
- Below it, the vault properties: **created**, **updated** and **tags**. The updated date changes on its own when you edit the text.
- At the bottom of the note, the **Mentioned in** panel: the notes that link to this one, with the lines where it appears. One click opens them.

## Tags

Type the tag and press Enter or a comma. The Studio suggests the tags you already use, from most used to least.

> [!tip] Tags inherited from the folder
> A new note in a folder gets the tags most notes in that folder already have. That way, the "Meetings" folder keeps the "meeting" tag without you having to remember.

## Organize by dragging

Drag a note or folder onto a folder to move it. Drop it in the empty space below the tree to send it to the top level. Links in other notes are fixed on their own.

## Keep it in the cloud

Vaults sync just like sites: through Blup Cloud (end-to-end encrypted) or a private GitHub repository. See [Sync your notes](../Blup%20Cloud/Sync%20your%20notes.md).
