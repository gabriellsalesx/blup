A **drawing** is a sheet for sketching: flows, diagrams, mind maps.

## Create one

Click **New drawing** in the side strip (`Ctrl+Alt+W`), use a folder's menu, or type `/` in a note and choose **New drawing**. The Studio creates the file in the **Drawings** folder (or in the folder of the menu) and opens it.

## Tools

Each tool has a letter:

| Letter | Tool |
| --- | --- |
| H | Move the board |
| V | Select |
| R | Rectangle |
| D | Diamond |
| O | Ellipse |
| A | Arrow |
| L | Line |
| P | Free drawing |
| T | Text |
| E | Eraser |

You can also paste images. Each element has a color, background (soft or solid), thickness, dashes and text size.

## Shortcuts

- Hold **Space** to move the board.
- **Arrow keys** move the selected item (with Shift, 10 at a time).
- **Enter** writes inside the shape or the text.
- `Ctrl+D` duplicates.
- `Ctrl+=`, `Ctrl+-` and `Ctrl+0` zoom in, zoom out and fit.
- **F** or `F11` turns on full screen. Esc leaves it.

## Export

**Export PNG** saves an image of the drawing in Attachments, ready to use in a note.

> [!info] Saves on its own
> The drawing is saved as `.draw` files while you work.
