A **database** is a list of things (clients, tasks, reading) with fields. Each item is a **note**: it has room to write, links to and from other notes, and shows up in search and on the map.

## Create one

1. Click **New database** in the side strip (`Ctrl+Alt+B`).
2. Pick a template:

| Template | Fields | Board by |
| --- | --- | --- |
| Clients | Company, Phone, E-mail, Temperature (Hot, Warm, Cold), Last contact | Temperature |
| Tasks | Status (To do, Doing, Done), Priority (High, Medium, Low), Due, Owner | Status |
| Reading | Author, Status (Want to read, Reading, Read), Rating, Link | Status |
| From scratch | Just the Status (To do, Done); you make the rest | Status |

3. Give it a name and click **Create**.

The database lives in the **Databases** folder: one file with the columns and a folder with one note per record.

## Views

- **Table**: each cell is edited like in a spreadsheet. Click the name to open the note.
- **Board**: one column for each option (for example, To do, Doing, Done). Drag a card to move it to another column.

In the bar: **Search everything…**, **Filter** by an option and **New** to create a record (type the name and press Enter).

## Columns

Click a column header to change its name, kind and options (with color), sort, or **Delete column**. The **+** at the end adds a new column.

| Kind | What for |
| --- | --- |
| Text, Number, Date | The basics |
| Single choice, Multiple choices | Options with color |
| Phone | With **Call** and **Open in WhatsApp** |
| E-mail | With **Write an e-mail** |
| Link | With **Open the link** |
| Yes/No | A checkbox |
| Link to a note | Connects the record to another note in the vault |

> [!tip] The fields live in the note too
> Open a record: the fields show in the properties, right after the tags. Change them there and the table changes too.

> [!note] Deleting
> Deleting a record sends the note to the Trash, with **Undo** in the notice. Deleting a column doesn't erase the values already in the notes.
