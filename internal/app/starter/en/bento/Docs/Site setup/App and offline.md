Every site published with Blup can be **installed as an app**, on phones and computers, and **opens without internet**. There is nothing to turn on.

## Install

- **Android and computers (Chrome, Edge):** an **Install app** button shows up in the site's footer, and the browser also offers an install icon in the address bar.
- **iPhone and iPad (Safari):** tap **Share** and then **Add to Home Screen**.

The app opens full screen, with the site's icon and name.

## The icon

Blup makes the icons for each device from the site's **favicon**. To change it, change the favicon on the **Site** screen of the Studio (see [Site settings](Site%20settings.md)). A square image, at least 512 pixels or in SVG, works best.

## Without internet

On the first visit, the browser saves the pages, the styles and the fonts. After that, the site opens even without internet.

- **Photos** are saved as the person sees them, so they are not all downloaded at once.
- **Comments and reactions** need internet; without it, the rest of the page works as usual.
- Each time you publish, the browser downloads the new version by itself.

The preview does not become an app, because it changes all the time; only the published site does.
