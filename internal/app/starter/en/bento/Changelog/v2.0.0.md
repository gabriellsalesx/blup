Say hello to **Blup Studio**, the Blup app for Linux, macOS and Windows. It is now the recommended way to use Blup. The command line keeps working with the same notes.

- An editor with the text already formatted and the site **preview** beside it.
- Screens to set up the site: Site, Sections, Authors, Comments, Cookies and Publish.
- A terminal with AI agents, with a copy of the notes before they start and a button to undo.
- A Trash to get back what was deleted.
- A new theme: **Nori**, a one-column blog.
