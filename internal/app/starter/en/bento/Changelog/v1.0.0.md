First version: the `blup` command line turns a folder of notes into a site, with the **Mochi** (blog) and **Bento** (product site) themes.

- Preview on your computer with `blup preview` and publish with `blup publish`.
- Free publishing on Cloudflare Workers or GitHub Pages.
