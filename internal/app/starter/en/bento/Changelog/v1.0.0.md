First version: the `blup` command line turns an Obsidian folder into a site, with the **Mochi** (blog) and **Bento** (product site) themes.

- Preview on your computer with `blup preview` and publish with `blup publish`.
- Free publishing on Cloudflare Pages or GitHub Pages.
