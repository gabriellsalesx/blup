Publishing on Cloudflare Workers or GitHub Pages is still free. But now there is a way with no setup at all: **Blup Cloud**.

## Publish

1. Click **Publish** and choose **Blup Cloud**.
2. Type the address you want. The Studio checks right away whether it is free, and suggests similar names when it isn't.
3. Publish.

The site lives at `yoursite.getblup.site`. The files go compressed, and each time you publish only what changed is uploaded.

## Sync

The **Sync** button keeps your notes on Blup Cloud, encrypted on your computer before they go up. Not even Blup can read them. From the Pro plan up, syncing happens in real time and keeps a version history.

Prefer GitHub? Syncing through a private repository is still there, and you don't need to know git.
