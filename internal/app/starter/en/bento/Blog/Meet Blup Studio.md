Blup started as a command line. Today, the recommended way to use it is **Blup Studio**, an app that puts everything in one window.

## Write while you see the site

The editor shows the text already formatted: headings, lists, links and images look the way they will on the site. Beside it, the **preview** shows the site page and follows the note you are editing.

Type `/` to insert headings, tables, callouts and images. Type `@` to mention another note or a date.

## Set up without touching code

Each part of the site has its own screen: **Site** (name, logo, menu and social links), **Sections**, **Authors**, **Languages**, **Comments**, **Cookies**, **Podcast** and **Publish**.

## And more

- **Translation** of notes and **narration** of posts as audio.
- **Note vaults**, for notes that don't become a site.
- **Sync** and **publish** with Blup Cloud.
- A terminal with AI agents, a trash and a history.

## And the command line?

It still works. The notes are Markdown files, and the `blup` command line can preview and publish them too.

Download the Studio at getblup.io.
