Um **banco de dados** é uma lista de coisas (clientes, tarefas, leituras) com campos. Cada item é uma **nota**: tem espaço para escrever, links de e para outras notas, e aparece na busca e no mapa.

## Criar

1. Clique em **Novo banco de dados** na faixa lateral (`Ctrl+Alt+B`).
2. Escolha um modelo:

| Modelo | Campos | Quadro por |
| --- | --- | --- |
| Clientes | Empresa, Telefone, E-mail, Temperatura (Quente, Morno, Frio), Último contato | Temperatura |
| Tarefas | Situação (A fazer, Fazendo, Feito), Prioridade (Alta, Média, Baixa), Prazo, Responsável | Situação |
| Leituras | Autor, Situação (Quero ler, Lendo, Lido), Nota, Link | Situação |
| Do zero | Só a Situação (A fazer, Feito); você cria o resto | Situação |

3. Dê um nome e clique em **Criar**.

O banco fica na pasta **Bancos de dados**: um arquivo com as colunas e uma pasta com uma nota por registro.

## Formas de ver

- **Tabela**: cada célula se edita como numa planilha. Clique no nome para abrir a nota.
- **Quadro**: uma coluna para cada opção (por exemplo, A fazer, Fazendo, Feito). Arraste o cartão para trocar de coluna.

Na barra: **Buscar em tudo…**, **Filtrar** por uma opção e **Novo** para criar um registro (escreva o nome e aperte Enter).

## Colunas

Clique no cabeçalho de uma coluna para mudar o nome, o tipo e as opções (com cor), ordenar ou **Apagar coluna**. O **+** no fim acrescenta uma coluna nova.

| Tipo | Para quê |
| --- | --- |
| Texto, Número, Data | O básico |
| Escolha única, Várias escolhas | Opções com cor |
| Telefone | Com **Ligar** e **Abrir no WhatsApp** |
| E-mail | Com **Escrever e-mail** |
| Link | Com **Abrir o link** |
| Sim/Não | Uma caixa de marcar |
| Ligação com nota | Liga o registro a outra nota do cofre |

> [!tip] Os campos também ficam na nota
> Abra um registro: os campos aparecem nas propriedades, logo depois das tags. Mudou lá, mudou na tabela.

> [!note] Apagar
> Apagar um registro manda a nota para a Lixeira, com **Desfazer** no aviso. Apagar uma coluna não apaga os valores que já estão nas notas.
