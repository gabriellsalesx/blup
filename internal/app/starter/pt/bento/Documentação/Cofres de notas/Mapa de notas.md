O **Mapa de notas** desenha o cofre inteiro: cada nota é um ponto e cada link entre notas é uma linha. Notas com mais links ficam maiores.

Abra pela faixa lateral ou com `Ctrl+Alt+G` (o mesmo atalho volta para Escrever).

## Mexer no mapa

- **Passe o mouse** num ponto: ele e os vizinhos se acendem.
- **Clique** para abrir a nota.
- **Arraste um ponto** para mudar de lugar.
- **Arraste o vazio** para mover o mapa e use a **roda do mouse** para aproximar e afastar.
- **Ver tudo** enquadra o mapa inteiro. **Ler as notas de novo** atualiza.

O mapa também se atualiza sozinho quando uma nota muda.

## Ajustes do mapa

O painel do canto tem quatro partes. Tudo fica salvo, e **Voltar ao padrão** desfaz.

| Parte | O que tem |
| --- | --- |
| Filtros | Busca (acende os nomes que batem), Pasta, Tag, Tags como pontos, Notas soltas, Canvas e desenhos, e **Em volta da nota aberta**, com a profundidade de 1 a 4 links |
| Grupos | Pinte as notas de uma pasta ou tag com uma cor |
| Exibição | Setas, Limite para mostrar os nomes, Tamanho das notas, Espessura das linhas e **Animar** (as notas surgem na ordem em que foram criadas) |
| Forças | Força do centro, de repulsão, dos links e distância dos links |

> [!tip] O que conta como link
> Links entre notas, `[[wikilinks]]`, cartões de nota num canvas e os campos **Ligação com nota** dos bancos de dados. Desenhos aparecem como pontos, mas não são lidos em busca de links.
