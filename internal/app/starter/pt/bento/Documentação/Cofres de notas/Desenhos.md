Um **desenho** é uma folha para esboçar: fluxos, esquemas, mapas mentais.

## Criar

Clique em **Novo desenho** na faixa lateral (`Ctrl+Alt+W`), use o menu de uma pasta ou digite `/` numa nota e escolha **Novo desenho**. O Studio cria o arquivo na pasta **Desenhos** (ou na pasta do menu) e já abre.

## Ferramentas

Cada ferramenta tem uma letra:

| Letra | Ferramenta |
| --- | --- |
| H | Mover a tela |
| V | Selecionar |
| R | Retângulo |
| D | Losango |
| O | Elipse |
| A | Seta |
| L | Linha |
| P | Desenho livre |
| T | Texto |
| E | Borracha |

Também dá para colar imagens. Cada elemento tem cor, fundo (suave ou sólido), espessura, tracejado e tamanho de texto.

## Atalhos

- **Espaço** segurado move a tela.
- **Setas** movem o selecionado (com Shift, de 10 em 10).
- **Enter** escreve dentro da forma ou do texto.
- `Ctrl+D` duplica.
- `Ctrl+=`, `Ctrl+-` e `Ctrl+0` aproximam, afastam e enquadram.
- **F** ou `F11` liga a tela cheia. Esc sai.

## Exportar

**Exportar PNG** salva uma imagem do desenho nos Anexos, pronta para usar numa nota.

> [!info] Salva sozinho
> O desenho é salvo em arquivos `.draw` enquanto você trabalha.
