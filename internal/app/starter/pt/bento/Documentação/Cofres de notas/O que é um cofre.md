Um **cofre de anotações** é uma pasta de notas que **não vira site**: só notas, sem tema, sem prévia e sem publicação. Serve para o diário, as ideias, os estudos, os clientes, as tarefas.

> [!info] Só no Blup Studio
> Os cofres e as ferramentas deles (nota do dia, mapa de notas, canvas, desenhos e bancos de dados) são do Studio. As notas continuam arquivos Markdown comuns, que abrem em qualquer editor.

## Criar um cofre

1. Na tela inicial, clique em **Criar cofre de anotações**.
2. Dê um nome, como "Minhas notas".
3. Confira onde as notas ficam. Dá para **usar uma pasta que já existe** ou **escolher outra pasta**.
4. Clique em **Criar cofre**. É só começar a escrever.

## A tela do cofre

A faixa lateral do cofre tem:

| Ícone | O que faz | Atalho |
| --- | --- | --- |
| Escrever | O editor e a árvore de notas | |
| Mapa de notas | As notas como pontos ligados pelos links | `Ctrl+Alt+G` |
| Anexos | Imagens e arquivos | |
| Novo canvas | Um quadro infinito com cartões e setas | `Ctrl+Alt+C` |
| Novo desenho | Formas, setas e traço livre | `Ctrl+Alt+W` |
| Novo banco de dados | Uma lista de coisas com campos | `Ctrl+Alt+B` |
| Nota do dia | A nota de hoje, com a hora | `Ctrl+Alt+D` |
| Sincronizar | Guarda as notas na nuvem | |
| Lixeira | O que foi apagado | |

A árvore mostra notas, pastas, canvases, desenhos e bancos de dados, cada um com o seu ícone.

## A página da nota

- No topo, o **nome da nota** em letra grande. Edite ali e aperte Enter para renomear o arquivo.
- Embaixo, as propriedades do cofre: **criado**, **atualizado** e **tags**. A data de atualização muda sozinha quando você edita o texto.
- No pé da nota, o painel **Mencionada em**: as notas que têm link para esta, com as linhas onde ela aparece. Um clique abre.

## Tags

Escreva a tag e aperte Enter ou vírgula. O Studio sugere as tags que você já usa, das mais usadas para as menos.

> [!tip] Tags herdadas da pasta
> Uma nota nova numa pasta ganha as tags que a maioria das notas daquela pasta já tem. Assim, a pasta "Reuniões" mantém a tag "reuniao" sem você lembrar.

## Organizar arrastando

Arraste uma nota ou pasta para cima de uma pasta para mover. Solte no espaço vazio embaixo da árvore para mandar para a raiz. Os links das outras notas são corrigidos sozinhos.

## Guardar na nuvem

Os cofres sincronizam como os sites: pelo Blup Cloud (criptografado de ponta a ponta) ou por um repositório privado do GitHub. Veja [Sincronizar as notas](../Blup%20Cloud/Sincronizar%20as%20notas.md).
