A tela **Anexos** mostra as imagens e arquivos que as notas usam. Eles chegam sozinhos quando você cola ou arrasta uma imagem, escolhe uma capa, o logo ou a foto de um autor.

## O que dá para fazer

- **Filtrar**: Todos, Imagens, Outros e **Sem uso**.
- **Buscar pelo nome**.
- **Adicionar arquivos** do computador.
- Ver **Usado em**: as notas que usam o arquivo, com link para abrir cada uma.
- **Renomear**: as notas que usam o arquivo são atualizadas.
- **Copiar para colar numa nota**: copia o link pronto.
- **Abrir no computador**, com o programa padrão.
- **Apagar**: vai para a Lixeira. Se alguma nota usa o arquivo, o Studio avisa antes.

> [!tip] Sem uso não vai para o site
> Um arquivo que nenhuma nota usa não é publicado. O filtro **Sem uso** ajuda a fazer uma faxina.

## O que o site faz com as imagens

Na publicação, o Blup gera versões menores e em WebP de cada imagem e entrega ao navegador só o tamanho de que ele precisa. Veja [Links e imagens](../Escrevendo/Links%20e%20imagens.md).

## A pasta Anexos

Os anexos ficam na pasta **Anexos** das notas, como arquivos comuns.
