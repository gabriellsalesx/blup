O Studio tem várias redes de proteção. Cada uma cobre um tipo de engano.

## Lixeira

Tudo que você apaga no Studio (notas, pastas, anexos, autores e seções) vai para a **Lixeira**, no fim da faixa lateral.

- **Restaurar** devolve o item ao lugar de onde saiu. Se já existe algo com o mesmo nome lá, o Studio não sobrescreve.
- **Apagar de vez** remove um item para sempre.
- **Esvaziar lixeira** remove tudo para sempre.

A lixeira fica na pasta do site, fora das notas: ela não vai para o site nem para a sincronização.

## Versões anteriores (Blup Cloud)

Com as notas sincronizadas pelo Blup Cloud num plano com histórico, clique com o botão direito numa nota e escolha **Versões anteriores**. Escolha uma versão para ver e, se quiser, **Trazer esta versão de volta**. A versão atual continua no histórico, então nada se perde.

Na Lixeira aparece também **Apagadas, guardadas no Blup Cloud**: notas apagadas que o histórico do seu plano ainda guarda, com **Trazer de volta**. Veja [Histórico de versões](../Blup%20Cloud/Histórico%20de%20versões.md).

## Desfazer o que a IA mudou

Antes de um agente de IA começar no terminal, o Studio guarda uma cópia das notas. Depois, **Ver o que a IA mudou** mostra as notas novas, alteradas e apagadas, e **Desfazer tudo** volta as notas para antes da IA. Veja [Terminal e agentes de IA](Terminal%20e%20agentes%20de%20IA.md).

## Cópia diária das notas

Em **Configurações > Geral**, **Cópia diária das notas** guarda um `.zip` por dia das notas do site ou cofre aberto, numa pasta que você escolhe, e mantém as últimas 7 cópias. **Copiar agora** faz uma cópia na hora.

> [!tip] Escolha uma pasta fora das notas
> Um disco externo ou uma pasta de outro serviço de nuvem são boas escolhas. A cópia nunca é guardada dentro das próprias notas.
