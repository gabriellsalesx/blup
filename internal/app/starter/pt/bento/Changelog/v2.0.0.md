Chegou o **Blup Studio**, o app do Blup para Linux, macOS e Windows. Ele passa a ser o jeito recomendado de usar o Blup. O Obsidian e a linha de comando continuam funcionando com as mesmas notas.

- Editor com o texto já formatado e a **prévia** do site ao lado.
- Telas para configurar o site: Site, Seções, Autores, Comentários, Cookies e Publicar.
- Terminal com agentes de IA, com cópia das notas antes e botão para desfazer.
- Lixeira para recuperar o que foi apagado.
- Tema novo: **Nori**, um blog de uma coluna.
