Primeira versão: a linha de comando `blup` transforma uma pasta do Obsidian em site, com os temas **Mochi** (blog) e **Bento** (site de produto).

- Prévia no computador com `blup ver` e publicação com `blup publicar`.
- Publicação de graça no Cloudflare Pages ou no GitHub Pages.
