| | Blup Cloud | Cloudflare Pages | GitHub Pages |
| --- | --- | --- | --- |
| Preço | Nos planos pagos | Grátis | Grátis |
| Endereço | `seusite.getblup.site` | `meusite.pages.dev` | `seunome.github.io/meusite` |
| Conta | A do Blup Cloud | Uma conta Cloudflare | Uma conta GitHub |
| Configurar | Nada | Uma chave de acesso | Uma chave de acesso |

## Qual escolher?

- **Blup Cloud** é o caminho mais simples: você escolhe o endereço e publica. O Studio confere se o nome está livre enquanto você digita.
- **Cloudflare Pages** e **GitHub Pages** são gratuitos e pedem uma conta no serviço e uma chave de acesso, que o Blup ajuda a criar.

Nos três, o Blup gera o site no seu computador e envia só os arquivos prontos.
