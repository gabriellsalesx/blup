Nem toda nota precisa virar site. Para as anotações do dia a dia, o Blup Studio tem os **cofres de anotações**: notas só suas, que nunca são publicadas.

## Criar um cofre

Na tela inicial do Studio, clique em **Criar cofre de anotações**, dê um nome e pronto: é só começar a escrever. Os sites e os cofres ficam lado a lado na tela inicial, e o seletor embaixo do menu ao lado troca de um para o outro.

## O que um cofre tem

- **Notas** com o mesmo editor dos sites, com data de criação, data de atualização e tags.
- **Mencionada em**: embaixo de cada nota, as outras notas que apontam para ela.
- **Mapa de notas**: cada nota é um ponto e cada link, uma linha. Bom para ver como as ideias se ligam.
- **Canvas**: um quadro livre com cartões de texto, notas, links e setas.
- **Desenhos**: formas, setas, texto e desenho à mão livre.
- **Bancos de dados**: listas de clientes, tarefas ou leituras, em tabela ou em quadro. Cada item é uma nota.
- **Nota do dia**: um clique abre a nota de hoje, com a hora, pronta para escrever.

Digite `@` para citar outra nota ou uma data, e `/` para inserir um título, uma lista, uma tabela, um desenho ou um canvas.

## Guardar e levar para outro computador

As notas do cofre são arquivos comuns, numa pasta do seu computador. Para ter as mesmas notas em outro computador, use o botão **Sincronizar**: pelo Blup Cloud, com criptografia de ponta a ponta, ou num repositório privado do GitHub. Veja [Sincronizar as notas](../Personalizando/Sincronizar%20as%20notas.md).

> [!info] Formatos abertos
> As notas de um cofre são arquivos Markdown comuns e abrem em qualquer editor de texto. O canvas usa o formato aberto JSON Canvas. Desenhos, bancos de dados, mapa de notas e nota do dia são recursos do próprio Studio.
