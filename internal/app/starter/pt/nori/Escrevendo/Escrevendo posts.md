Para criar um post, clique em **Nova nota** no painel Arquivos, dê um nome e escreva. Só isso. O resto é opcional e fica no painel **Propriedades**, em cima do editor. Clique no nome do painel para abrir ou fechar.

## As propriedades

| No painel | Para que serve |
| --- | --- |
| **Título** | Título do post. Vazio, vale o nome da nota. |
| **Descrição** | Resumo nas listas, no Google e ao compartilhar. |
| **Data** | Data do post. |
| **Tags** | Assuntos. Escreva e aperte Enter. Cada tag ganha uma página. |
| **Capa** | A imagem de capa do post. |
| **Autores** | Quem escreveu, em **Mais opções**. Vazio, vale o autor do site. |
| **Rascunho** | Deixa a nota fora do site. Ela aparece só na prévia. |
| **Escondida** | Publica, mas tira das listas e do Google. |
| **Senha** | Pede uma senha para ler. Veja [Posts com senha](Posts%20com%20senha.md). |

O Studio guarda tudo no topo da própria nota. Abra este post e veja as propriedades dele no painel.

## Links entre notas

Na barra de formatação, clique em **Link para outra nota** e escolha a nota. Ou digite `[[` no texto: o Studio sugere as notas pelo nome.

No site, ele vira o link da página. Exemplo: [Formatação que funciona](Formatação%20que%20funciona.md).

Para um link de outro site, use o botão **Link** (Ctrl+K).

> [!tip] Renomeou uma nota?
> Pode renomear sem medo. O Studio atualiza sozinho os links que apontam para ela.

## Imagens

Cole ou arraste a imagem para dentro da nota, ou use o botão **Imagem do computador**. O Studio guarda o arquivo na pasta **Anexos** sozinho. O Blup gera versões menores e modernas (WebP) de cada imagem, e o navegador baixa só o tamanho que precisa.

![Blup escrevendo num cartão de nota](../Anexos/blup-escrever.jpg)

O texto entre colchetes é a descrição da imagem: ajuda quem usa leitor de tela e o Google.

A tela **Anexos**, no menu ao lado, mostra todas as imagens e arquivos que as notas usam. O filtro **Sem uso** acha o que sobrou.

## Organizar em seções

Crie uma pasta com **Nova pasta**, como **Viagens**, e coloque posts nela: o site ganha a seção Viagens, com página própria e item no menu. Para dar título e descrição à seção, crie uma nota **_index** dentro dela, como a desta seção.

## Corretor ortográfico

O Studio sublinha as palavras com erro enquanto você escreve. Clique com o botão direito na palavra para ver as sugestões ou adicionar a palavra ao dicionário.
